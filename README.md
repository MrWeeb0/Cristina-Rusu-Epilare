# Cristina Rusu — site de previzualizare

Preview static pentru profilul [@cristinarusu.md](https://www.instagram.com/cristinarusu.md/), cu layout bento modular și paleta olive–auriu.

## Deschidere locală

Deschide `index.html` sau pornește un server static din acest director:

```powershell
python -m http.server 4318
```

Apoi deschide `http://127.0.0.1:4318/`.

## Publicare pe GitHub Pages

În repository, deschide **Settings → Pages**, selectează **Deploy from a branch**, apoi alege **main** și folderul **/(root)**. După salvare, site-ul va fi disponibil la:

`https://mrweeb0.github.io/Cristina-Rusu-Epilare/`

## Conținut folosit

- Servicii, adresă și telefon: detaliile oferite de Nicu în conversație.
- Curs de epilare: card de înscriere cu mesaj precompletat către WhatsApp-ul Cristinei; fără preț sau durată inventate.
- Culori de brand: interpretate din captura cu pictogramele Instagram — verde-oliv/charcoal și auriu mat.
- Fotografia este editorială, folosită pentru preview, și trebuie înlocuită cu o fotografie proprie înainte de publicare.
  - [Imagine laminare gene — Nastiia Nikitenko](https://unsplash.com/photos/a-woman-is-getting-her-hair-cut-by-a-hair-stylist-NNGZRpc-x90)

Nu sunt incluse prețuri, servicii suplimentare sau afirmații despre rezultate care nu au fost furnizate.
